# Входящие заказы сайта → Water19 Pro 2.0

Проверено со схемой базы 2 из Water19Pro2_Windows_Source.zip. Перед использованием закройте Water19, сохраните резервную копию и проверьте файл соответствий марок. Номера ID в example — пример начального каталога, сверяйте с вашей базой.

1. На хостинге: `php backend/manage.php bridge-token`. Ключ показывается один раз. Повтор команды отзовёт старый ключ. Не вставляйте ключ в HTML, URL, Git или команды.
2. Скопируйте папку integration на ПК с Python 3.12. Сторонние библиотеки не нужны.
3. Скопируйте product-map.example.json в product-map.json и задайте реальные ID Water19.
4. Получите входящие: `python water19_bridge.py --site https://чистая-вода.site`. Ключ вводится скрыто. Файл site-inbox.json содержит данные покупателей — храните в закрытой папке.
5. Импорт конкретного заказа с резервной копией:
   `python water19_bridge.py --site https://чистая-вода.site --db C:\Water19\data\water19_v2.sqlite3 --map product-map.json --order CW-НОМЕР`
6. Заказ создаётся как «Новый»: только резерв, без продажи, оплаты и фактического списания склада. Маркер импорта находится в той же транзакции. Повтор ID возвращает прежний номер. Записи о клиентах выбираются по телефону И адресу. Старые профили не переписываются.
7. В Water19 подтвердите доставку и оплату обычным способом. В панели сайта вручную поддерживайте отображаемый статус. Связанные номера visible в резервной копии сайта и журнале. Это импорт заявок, не синхронизация двух бухгалтерий: сверяйте остатки и оплаты и выберите Water19 основным учётом.

Поддерживаемый прямой импорт: непроведённые заказы воды 19 л без оплаты. В Water19 2.0 каждая строка считается возвратной бутылью; поэтому 10 л, новые пустые бутыли и помпы остаются во входящих для ручного разбора. Их нельзя автоматически записывать как 19-литровую воду. Поддержка смешанных заказов требует обновления модели Water19.

Сайт использует суммы в рублях целыми числами; Water19 — в копейках. Доставка уже включена в цену позиции; отдельная доставка в Water19 равна нулю. Изменившийся после импорта заказ не переписывается автоматически. Перенос завершённых заказов и платежей не выполняется.
