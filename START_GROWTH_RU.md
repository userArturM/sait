# Мобильные заказы, повторные покупки и аналитика

Обновление от 23 октября 2026 года. Дополняет START_OPERATIONS_RU.md.

## Что изменено

- Мобильная форма в одну колонку, поля от 48 px, основные кнопки от 44 px, шрифт полей 16 px. Заголовок и закрытие корзины остаются доступными при прокрутке. Итог заказа не перекрывает поля. При переходе к оформлению клавиатура не открывается автоматически.
- Повтор заказа сначала запрашивает актуальные цены и доступное количество на сервере с учётом резерва. Недоступные товары исключаются с пояснением. Текущая непустая корзина заменяется только после подтверждения. Сам повтор не создаёт заказ. Дату, тару и итог нужно проверить заново; наличие окончательно проверяется при отправке.
- Адреса сохраняются в кабинете вместе с населённым пунктом. Выбор адреса меняет зону, цены и минимальное количество бутылей. Старые адреса без зоны остаются доступны, но требуют проверки населённого пункта. Адрес гостя в браузере не сохраняется.
- В истории заказа есть «Напомнить о воде». Флажок выключен по умолчанию. Можно выбрать 7, 14 или 30 дней, выключить или перенести напоминание. Уведомление отображается в кабинете, когда покупатель заходит на сайт; для уведомления вне сайта предлагается файл календаря ICS. SMS, письма, push и автоматические заказы для этой функции не включаются.
- Напоминание хранит состав товаров и зону без имени, телефона и адреса, поэтому его можно пересчитать после очистки контактов старого заказа. Оно удаляется вместе с кабинетом. Отключение на сайте не удаляет ранее импортированное событие из календаря телефона. При переносе даты календарное событие тоже нужно изменить самостоятельно. Поддержка уведомления и повторного импорта зависит от приложения календаря.

## Аналитика: подготовленный код и настройка счётчика

Сохранён существующий номер счётчика Яндекс Метрики **113385913**. Перед запуском проверьте, что это ваш счётчик. Внешний кабинет Метрики не изменялся: доступа к нему нет.

В Метрике создайте цели типа «JavaScript-событие» с точными идентификаторами:

| Идентификатор | Действие |
| --- | --- |
| catalog_view | Просмотр каталога после разрешения аналитики |
| product_view | Открытие подробностей товара |
| add_to_cart | Нажатие добавления товара |
| remove_from_cart | Нажатие уменьшения количества |
| cart_view | Открытие корзины |
| checkout_start | Переход к оформлению |
| checkout_contact | Введён телефон подходящего формата |
| checkout_delivery | Введён адрес с номером дома либо выбран самовывоз |
| checkout_submit | Отправка заказа на сервер |
| checkout_error | Ошибка обязательного поля либо ответ с ошибкой/сбой отправки |
| order_saved | Сервер подтвердил сохранение заказа |
| repeat_order | Восстановлен состав повторного заказа |

Основная последовательность для сравнения: catalog_view → add_to_cart → cart_view → checkout_start → checkout_submit → order_saved. Дополнительно сравнивайте checkout_contact, checkout_delivery и checkout_error для поиска проблем формы. Поле телефона и адреса учитывается один раз за открытое оформление; нажатия и повторные попытки отправки могут учитываться несколько раз. Анализируйте визиты/посетителей с достижением цели, а не простое отношение количества кликов. Событие order_saved означает сохранение заявки, не оплату и не доставку.

Счётчик загружается только после разрешения. В целях передаётся только имя события: без телефона, имени, адреса, комментария, ID пользователя и заказа. Вебвизор, карта кликов и отслеживание ссылок выключены. В адресе просмотра убраны query-параметры. Кабинет и админка исключены из загрузки счётчика; покупки внутри кабинета поэтому не входят в эту воронку. Отказавшиеся от аналитики и посетители с блокировщиками тоже не входят. Не используйте Метрику как источник точного числа заказов — для этого есть серверная база.

После установки создайте цели и проведите контрольный заказ с разрешённой аналитикой. Проверьте поступление событий в своём счётчике и исключите собственные тестовые визиты из рабочих отчётов. В этой поставке вызовы проверены локальным перехватчиком; приём данных внешним счётчиком не подтверждён.

Официальная справка: https://yandex.ru/support/metrica/en/general/goal-js-event
