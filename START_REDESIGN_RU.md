# Как установить обновлённый сайт на REG.RU

Это полная версия сайта с новым светлым оформлением. Отчёт и результаты проверок находятся в docs/CRYSTAL4_REDESIGN_RU.md.

1. В панели REG.RU сделайте резервную копию текущих файлов сайта и приватного каталога данных.
2. Распакуйте reg.ru.zip на компьютере. В корне архива лежит index.html: содержимое загружается прямо в действующий корень сайта (например, public_html), без дополнительной папки.
3. Замените файлы из архива. Существующий backend/config.php и приватный каталог cw-private сохраните; в архиве нет их замены. Не удаляйте существующие assets/uploads.
4. Если сайт уже настроен, повторно setup.php не запускайте. Администратор, покупатели и заказы сохраняются в существующем приватном каталоге данных.
5. Откройте главную, каталог, контакты, кабинет и админ-панель. Проверьте телефон, цены, самовывоз, выбранный населённый пункт, корзину и доступность оформления.
6. Если показывается старый дизайн, обновите страницу Ctrl+F5. Версия service worker изменена, чтобы обновить кеш оформления.
7. При необходимости отката восстановите файлы из резервной копии, сохранив актуальные данные заказов.

Новые файлы оформления: crystal.css, crystal.js, assets/crystal-landscape.svg. Изменены страницы, app.js и sw.js. PHP-обработчики не изменены.

Существующие настройки заголовка и текста главной в админ-панели имеют приоритет над текстом в index.html — это сохранено намеренно.

Для новой установки следуйте прежней инструкции docs/INSTALL_REG_RU.md. На рабочий хостинг из этой среды файлы не загружались.
