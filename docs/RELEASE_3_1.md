# Чистая вода 3.1 — результат доработки

Подготовлено 13.10.2026 для PHP 8.2+ / Apache. На REG.RU не установлено.

## Витрина

- Корзина с количеством и суммой в шапке компьютера; нижняя навигация на телефоне.
- Доставка/самовывоз и населённый пункт доступны уже на главной, сумма пересчитывается.
- Фильтры объёма, бренда/названия, предельной цены, поиск и сортировка.
- Подробные карточки с полями изготовителя, состава, хранения и другой информации, фото этикетки. Факты из отсутствующих документов поставщика не придуманы.
- Цена воды при обмене и ориентир первой покупки с новой бутылью показаны отдельно.
- Оформление на компьютере в две колонки с составом и итогом; на узком экране — одна колонка, прокрутка диалога и крупные поля.
- Новая тара добавляется по явному выбору. Переключение на обмен убирает только автоматическую добавку; вручную выбранные бутыли сохраняются. Изменение количества воды пересчитывает тару.
- Проверка формата телефона у поля, ошибка отправки в форме. Сохранённые адреса и повтор заказа продолжают работать.
- Подтверждение с номером, суммой, составом, адресом и желаемым интервалом; скачивание текстового подтверждения. Это не кассовый чек.

## Панель владельца

- Полное создание/редактирование карточек, загрузка фото и этикеток, поиск товаров, цены, остатки, публикация/скрытие.
- Заголовок и текст главной, объявление, подборка товаров, серверная пауза/возобновление новых заказов.
- Смена пароля с проверкой старого и отзывом других администраторских сессий.
- Заказы, клиенты, расчёты, регулярные заявки, CSV, JSON и журнал.
- Раздел документов и список карточек с отсутствующими сведениями.
- Защита устаревших форм: конфликт версии товара/настроек, включая обновление остатка после доставки.
- Загрузка фото проверяет содержимое, тип, размер и размеры изображения. Нет загрузки SVG, HTML или исполняемых файлов. Файлы получают случайные имена.
- Хеши и копии принятых документов сохраняются в приватной папке. JSON-копия состояния не заменяет отдельный backup фотографий/архива редакций и конфигурации.

## Воспроизведение

Запускайте тесты только на отдельной распакованной копии с временным data_dir вне web-корня. HTTP-наборы создают заказы, меняют товары и пароль; на рабочей базе их запускать нельзя. Пароль CW-test-admin-password-2026 относится только к тестовой среде.

- `php tests/core_test.php` — с backend/config.php, направленным в временный приватный каталог.
- `python3 tests/http_test.py` — сервер запущен отдельно; переменная CW_TEST_BASE указывает его URL, тестовый администратор предварительно создан.
- `python3 tests/admin_v31_test.py` — другая чистая тестовая база, тот же исходный тестовый пароль. В конце он изменяется тестом.
- `node tests/browser_test.cjs` — из корня отдельной тестовой копии, временная конфигурация и исходный тестовый пароль; нужен Playwright, CW_PLAYWRIGHT_MODULE и при необходимости CW_CHROMIUM_PATH/CW_PHP_BINARY.
- `node tests/ui_v31_test.cjs` — отдельная копия БЕЗ backend/config.php. Скрипт сам создаёт временную конфигурацию и тестового владельца, удаляет конфигурацию после завершения. Нужны те же переменные среды; результаты в tests/v31-output.
- `python3 tests/static_check.py` — проверка статических ссылок и HTML.

Адаптер Water19 не изменялся. Новая совместимость с изменениями Water19 из других проектов не заявляется.
