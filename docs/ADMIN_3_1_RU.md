# Панель управления 3.1

Открывается по адресу вашего сайта с окончанием `/admin.html`. На действующем домене новая панель появится после установки этого архива. Общего готового пароля нет: владелец создаёт свой через setup.php по INSTALL_REG_RU.md. Уже установленный пароль сохраняется при обновлении.

## Товары

1. Войдите → «Каталог и склад» → «Добавить товар».
2. Укажите название, описание, категорию, объём, цены доставки и магазина. Цена доставки задаётся для Пластуновской; для воды в Динской/Украинской действует прежняя надбавка 50 ₽.
3. Загрузите фото товара и при необходимости этикетки. PNG/JPEG/WebP до 3 МБ, сторона до 6000 пикселей, площадь до 16 Мп. SVG и исполняемые файлы не принимаются. PHP должен иметь запись в assets/uploads; нужен доступ к getimagesizefromstring. Имя файла генерирует сервер.
4. Заполните реальные сведения с этикетки и документов. Объём и категория влияют на расчёты и тару. Для системного товара «Бутыль тара» категория и объём защищены от изменения.
5. Если сведений пока нет, выберите «Скрыт». Затем сохраните. Незаполненные обязательные сведения не выдумывайте.
6. Для изменения существующего товара нажмите «Полная карточка». Быстрая форма ниже позволяет менять цены, остатки и видимость.
7. Пустой остаток означает, что количественный учёт отключён. Вводите физический остаток, включая резерв; сервер не разрешит поставить его ниже уже зарезервированного количества.

Для удаления с витрины используйте «Скрыть»: история заказов сохраняется. Цены/описания уже принятых заказов не переписываются. Устаревшая вкладка получает сообщение о конфликте — обновите панель, проверьте новые значения и повторите правку. Списание после доставки также меняет версию товара.

Фото загружается до сохранения формы. Если форму закрыть, файл останется неиспользованным. Удалять неиспользуемые фото следует через хостинг после резервирования и проверки ссылок. Дубликаты фото автоматически не очищаются.

## Сайт и безопасность

Можно менять заголовок/описание главной, объявление на сайте, подборку до 8 товаров на главной и включать/приостанавливать новые заказы. Скрытые товары в подборке не показываются. Изменения видны после обновления страницы. HTML в текстовых полях не исполняется.

Приостановка проверяется сервером даже для ранее открытой корзины. Уже принятые заказы остаются доступными, повторная отправка того же сохранённого заказа не создаёт дубль. Это не отключает регистрацию кабинета: для полного прекращения доступа используйте обслуживание на хостинге.

Смена пароля требует текущий пароль и новый не короче 16 символов. Другие администраторские сеансы отзываются при следующем запросе. 2FA не подключена; не используйте общий пароль на других сайтах.

Номер +7 928 223-53-33, реквизиты, юридические страницы, тарифные правила и серверная почта не редактируются произвольным HTML из панели. Их изменение требует согласования связанных страниц и конфигурации. Панель управляет главной страницей и каталогом, а не любым файлом хостинга.

## Заказы, клиенты, документы

Заказы: поиск, статусы, оплаты, фактически полученная тара, повтор почтового уведомления. Долг считается по завершённым заказам; суммы реальных оплат вводит владелец. Клиенты сгруппированы по телефону, это не проверка личности.

«Документы» содержит ссылки на действующие тексты, список неполных карточек и вопросы до запуска. Раздел не подтверждает юридическое соответствие. Полный разбор — LEGAL_REVIEW_3_1.md.

## Резервные копии

CSV — таблица заказов. JSON — товары, настройки главной, заказы, кабинеты, подписки и события. Это НЕ копия файлов изображений, серверной конфигурации и пароля администратора.

Отдельно защищённо резервируйте `assets/uploads`, конфигурацию, весь приватный каталог, включая `legal` (редакции принятых документов) и `admin.json`. Не размещайте приватную копию в web-каталоге. Для восстановления JSON нужна команда из INSTALL_REG_RU.md; произвольной загрузки базы из браузера нет.
