# Цены по населённым пунктам

Войдите в admin.html → «Каталог и склад». В каждой карточке доступны цены за одну единицу товара: Пластуновская, Динская, Украинская и Самовывоз. Заполните все четыре поля целыми рублями и нажмите «Сохранить». Те же поля есть в полной карточке и при добавлении товара. Цена 0 допускается и означает бесплатный товар — проверяйте её перед сохранением.

Укажите итоговую цену товара для выбранного пункта: дополнительных 50 рублей после сохранения карточки не начисляется. Цена применяется также к таре и аксессуарам, если вы зададите для них разные суммы. В разделе «Условия доставки» теперь можно добавлять пункты; инструкция — START_ADMIN_RU.md.

При обновлении существующего сайта товары без новых полей сохраняют прежние цены: базовая доставка для Пластуновской и прежняя надбавка 50 рублей к воде для Динской и Украинской. Админка показывает эти суммы в отдельных полях. После первого сохранения товара они становятся независимыми. Текущая база не перезаписывается.

Посетитель получает актуальные цены после загрузки каталога. При изменении суммы до отправки заказа сервер отклоняет устаревший итог, чтобы покупатель подтвердил актуальную сумму. Уже оформленные заказы не пересчитываются. Повторный заказ рассчитывается заново по текущим ценам и наличию.

## Установка обновления
Сделайте резервную копию сайта и данных. Загрузите содержимое архива в корень сайта с заменой файлов, сохранив свой backend/config.php, защищённый каталог данных вне сайта и загруженные фотографии assets/uploads. Не запускайте первоначальную настройку заново. Обновите страницу админки; после сохранения проверьте каталог для каждого населённого пункта.

## Проверка
Пройдены 21 проверка цен на PHP и 13 HTTP-проверок: сохранение через обе формы API, доступ только администратора, конфликт версий, валидация сумм, выдача цен каталогу, оформление заказа, неизменность старого заказа и пересчёт повторного заказа. Также пройдены 112 существующих проверок основной логики, операций и повторных покупок.
