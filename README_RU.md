# Чистая вода 3.1 — сборка для REG.RU

Сайт PHP 8.2+ / Apache 2.4, мобильный интерфейс, сервер заказов, личные кабинеты и панель владельца с отдельными ролями диспетчера и курьера. Каталог, фотографии, исходные цены, телефон +7 928 223-53-33 и адрес магазина сохранены.

Начните с `docs/INSTALL_REG_RU.md`. Веб-файлы находятся в корне архива. Папки docs, tests и integration содержат инструкции, тесты и адаптер; они закрыты от HTTP и не нужны покупателю.

## Возможности

- Адаптивный интерфейс: на компьютере корзина в шапке и оформление в две колонки; на телефоне нижняя навигация. Фильтры по объёму, бренду и цене, подробные карточки и этикетки.
- Доставка в Пластуновскую/Динскую/Украинскую и заказ на самовывоз; отдельные цены. Доставка включена в цену выбранного населённого пункта.
- Серверная проверка количества, минимального заказа, цены, даты, интервала, оплаты и независимых согласий. Тара учитывается отдельно; новая добавляется по цене каталога.
- Устойчивое сохранение под блокировкой и атомарной заменой файла; повторная отправка с тем же ключом не создаёт дубликат. После ошибки сети можно восстановить результат по ключу с той же сессии.
- Кабинет по телефону и паролю, отдельные адреса, история собственных заказов, повтор по текущим ценам и заявки на регулярное согласование доставки.
- Защищённая панель: статусы заказов, оплаты, долг завершённых заказов, фактическая тара, цены, видимость товаров, остатки и резервы, клиенты, журнал, CSV/JSON.
- Серверные копии перед каждым изменением: последние 30. Локальное восстановление через CLI.
- Уведомления почтой после сохранения заказа, без адреса/телефона в письме. Почтовая отправка по умолчанию выключена до настройки отправителя.
- Метрика после отдельного добровольного выбора; Вебвизор отключён. Кабинеты и панель не отправляют аналитику.
- API и приватные страницы не сохраняются service worker. Offline — просмотр публичного каталога с предупреждением, оформление выключено.
- SEO: метаданные, LocalBusiness, актуальные Product/Offer в JS каталога, sitemap и robots.
- Адаптер входящих заявок Water19 Pro 2.0. Прямой перенос — вода 19 л без ранее проведённых оплат. Защита от повторного импорта и резервная копия базы перед операцией.

## Границы этой версии

- Архив не устанавливается сам на REG.RU. Реальный SSL, настройки Apache и доставка писем на вашем тарифе требуют проверки после загрузки.
- Интервалы — пожелания покупателя. Подтверждает владелец. Вместимость интервала задаётся в config.php; по умолчанию ограничение выключено.
- Вход по телефону не подтверждает владение номером. Поэтому гостевые заказы не связываются с кабинетом по номеру; доступны только заказы, созданные в его сессии. Для восстановления выдаётся отдельный ключ. SMS, OAuth, платёжный эквайринг и 2FA не подключены.
- Регулярная доставка — заявка в панели, без автоматических заказов, уведомлений, платежей и списаний.
- Статусы и платежи Water19 автоматически обратно не синхронизируются. Смешанные заказы остаются во входящих для ручного разбора. Используйте Water19 как основной учёт и сверяйте сайт.
- Количественные остатки при первой установке не выдумываются: null означает учёт выключен. Владелец вводит реальные количества. Сток = физический остаток, резерв считается автоматически. Тара для сверки не означает залог или денежный долг.
- Цены в целых рублях. Нет закупочной себестоимости, расчёта прибыли, фискальных чеков, списаний по банковскому API, частичных товарных возвратов.
- Управление каталогом: полные карточки, фото и этикетки из панели, цены, видимость, остатки. Настройки главной, объявление, подборка товаров, пауза новых заказов, смена пароля. Пауза заказов не выключает регистрацию. Скрытие товара сохраняет историю. Активную базу заменять seed нельзя.
- Хранилище рассчитано на небольшой сайт одного владельца. При существенном росте заказов потребуется миграция в транзакционную СУБД, фоновая очередь уведомлений и выделенный мониторинг.
- Резервные копии и SQLite Water19 не зашифрованы приложением. Ограничьте доступ, используйте защищённый носитель.
- Юридические тексты обновлены под фактические функции; это не подтверждение подачи уведомления РКН или полной юридической готовности. Обязательные неизвестные сведения перечислены в docs/RKN_FIELDS_RU.md.
